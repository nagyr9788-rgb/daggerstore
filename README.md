# FC27 BOOST – static site

1. Open `app.js` and replace `ELDORADO_URL` with your Eldorado offer link.
2. Create a GitHub repo, upload `index.html`, `style.css`, `app.js` (and this README) to the root.
3. Repo Settings → Pages → Source: "Deploy from a branch" → `main` / root → Save.
4. Your site goes live at `https://<username>.github.io/<repo>/` in a minute or two.
